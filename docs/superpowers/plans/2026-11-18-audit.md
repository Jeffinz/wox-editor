# Audit โปรเจ็ค wox-editor (2026-11-18) — แผนงาน

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development หรือ superpowers:executing-plans ทำงานตาม checkbox (`- [x]`)

**Goal:** รู้สภาพจริงของ repo ก่อนเริ่มงาน (ก) ได้แก่ ความถูกต้องของสคริปต์, ความจริงของเอกสาร, ช่องโหว่ฝั่ง security, ความทนต่อ build ใหม่, ช่องว่างของเทส และภาระ Performance แล้วได้รายการ finding ที่มีหลักฐาน `file:line` จัดลำดับความสำคัญ พร้อมข้อเสนอว่าควรแก้ก่อนงาน (ก) หรือไม่

**ไม่ใช่เป้าหมาย:** ไม่แก้โค้ดในงานนี้ ไม่ bump `@version` ไม่ปล่อยเวอร์ชัน ไม่แตะเกม ไม่ทดสอบในเบราว์เซอร์เอง (ระบุเป็นข้อที่ต้องให้นายท่านตรวจ)

**Tech Stack:** userscript ไฟล์เดียว (Tampermonkey, ES2022), Node 22 `node:test`, `tools/fetch-bundle.mjs`, `gh` CLI สำหรับตรวจ repo สาธารณะ

**Baseline ที่วัดแล้ว 2026-11-18:** `git status` clean, `node --check wox-editor.user.js` ผ่าน, `node --test "tests/**/*.test.mjs"` → pass 24, fail 0, skipped 1, ไม่มี `package.json`

## Global Constraints

- Audit เป็น read-only: ห้ามแก้ `wox-editor.user.js`, `tools/`, `tests/` ในงานนี้
- ทุก finding ต้องมีหลักฐานอย่างน้อยหนึ่งอย่าง: `file:line`, คำสั่งที่รันได้ซ้ำพร้อมผล, หรือข้อความ error จริง — ห้ามเขียนจากความจำ
- ข้อที่ตัดสินได้เฉพาะในเบราว์เซอร์/เกมจริง ให้เขียนว่า "ต้องทดสอบในเกม" ห้ามเดาผล
- ห้ามคัดลอกเนื้อหาเกมหรือ bundle ลง repo (`.gitignore` มี `src/`, `snapshots/`, `index.html`, `bundle/`)
- ผลลัพธ์อยู่ที่ `docs/superpowers/notes/2026-11-18-audit-findings.md` ไฟล์เดียว ส่วน plan นี้เก็บ checkbox ความคืบหน้า
- ทำงานบน branch `audit/2026-11-18` แยกจาก `main`

## Review Focus

1. **เอกสารโกหกหรือไม่** — CLAUDE.md/HANDOFF อ้างเลขบรรทัด, จำนวนเทส, offset, สถานะ `SIM` แต่โค้ดเปลี่ยนไปแล้ว ถ้าปล่อยไว้ session ถัดไปจะไล่ผิดที่
2. **ความปลอดภัยของ repo สาธารณะ** — `src/` ถูก gitignore แล้ว แต่ต้องพิสูจน์ว่าไม่เคยหลุดเข้า history
3. **จุดพังเงียบ** — dead branch ที่ `if (!SIM) return` ทำให้แผงขึ้นว่างโดยไม่มี error ผู้ใช้เห็นว่า "พัง" แต่ไม่รู้สาเหตุ
4. **esc() ไม่ escape `'`** — ปลอดภัยเฉพาะที่ที่ใช้ double quote; ต้องไล่ทุกจุด interpolate
5. **ทน build ใหม่แค่ไหน** — `LOC.IS` ใช้ค่าคงที่จาก build `mwkobenp` ถ้าเกมเปลี่ยน ค่าคงที่ตายทันทีและเทสจะยังผ่านด้วย fixture เดิม
